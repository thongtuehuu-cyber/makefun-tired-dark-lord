A 100-word monologue for a fantasy villain who is secretly just very tired — a tithe-collecting demon of Hell who cannot recall the soul's name, stalls on the page number, and hides behind the receipt. The tiredness lives in the rhythm, the pauses and the deflections, never in a plain statement. `main.py` deterministically writes the monologue as one line (97 words, 494 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
